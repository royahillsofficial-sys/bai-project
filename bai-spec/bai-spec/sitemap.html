What changes from the legacy screens

LegacyModernized
"Payment Options – OLD / NEW" plus separate Help menusOne menu driven by county config. Help moves into a "How this works" panel on each page.
"Multiple Payments" menu itemA global cart in the top bar that works across every tax type
"Error on Page" pop-ups in red capitalsInline messages that explain the problem and offer the next action, such as "Pay the balance"
CAPTCHA on its own page before checkoutA human check inside the cart review step
eCheck form with static check imagesA live check preview that highlights each number as it is typed
Different search screen for every serviceOne search component configured per service
"Show 25 entries / First Previous Next Last" tablesResponsive tables that become cards on phones
Terms repeated per serviceShown once per session
